# AI-QA

This section covers how I use AI as part of QA work — both the general workflow
practices and the specific tools I've built.

The stronger story here isn't any single tool, it's how AI fits into a QA engineer's
day-to-day process: multi-agent graph workflows, AI-assisted automation framework
support, and tools like MCP. That general practice is the lead content; the projects
below are the supporting showcase.

## Contents

- **[Multi-Agent Workflows](./Multi-Agent-Workflows/)** *(in development)* —
  multi-agent graph-style QA workflows, AI-assisted UI-check/automation-framework
  support, and the value of MCP in an AI/QA workflow. This is the primary content for
  this section.
- **[AI Dojo](./AI-Dojo/)** — a local-first QA training app powered by Qwen2.5-Coder
  (separate live project, linked from here).
- **[Test Case Generator](./Test-Case-Generator/)** — a tool using Google's Gemini API
  to generate structured test case documents from a prompt or a saved scenario.

More tools will be added here over time.
